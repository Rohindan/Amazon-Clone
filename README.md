# 🛒 Amazon Clone

A front-end clone of the Amazon website created using **HTML and CSS**. This project was built to practice web development fundamentals, including page structure, styling, layouts, navigation bars, product sections, and responsive design concepts.

## 📌 Project Overview

This project recreates the visual design and layout of Amazon's homepage using HTML and CSS.

The goal of this project was to improve my understanding of:

- HTML structure and semantic elements
- CSS styling and layouts
- Flexbox
- Navigation bars
- Product cards and sections
- Images and external resources
- Positioning and spacing
- Building a real-world website layout from scratch

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**

## ✨ Features

- Amazon-style navigation bar
- Amazon logo section
- Search bar
- Account and cart sections
- Hero/banner section
- Product/category cards
- Product images
- Footer section
- Amazon-inspired layout and styling

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/Rohindan/Amazon-Clone.git
```

2. Open the project folder.

3. Open `main.html` in your browser.

That's it! 🎉
